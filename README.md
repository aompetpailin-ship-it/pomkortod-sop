# ระบบ SOP (Standard Operating Procedure) ร้านไก่ทอด "ผมขอทอด" (Pom Khor Thod)

ระบบคู่มือการปฏิบัติงานมาตรฐาน สำหรับร้านไก่ทอด **"ผมขอทอด"** ออกแบบมาเพื่อให้พนักงานทุกแผนก (ผู้จัดการ/แอดมิน, พนักงานครัว, และพนักงานหน้าร้าน) สามารถเข้าถึง อัปเดต และใช้งานคู่มือการทำอาหารและการบริการได้อย่างถูกต้อง รวดเร็ว ผ่านคอมพิวเตอร์ แท็บเล็ต และมือถือ

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

1. **สิทธิ์การเข้าถึงข้อมูลแบ่งตามบทบาท (Role-Based Access Control - RBAC):**
   - 👑 **Admin / Manager:** เข้าถึงข้อมูลทั้งหมด สามารถเพิ่ม แก้ไข ลบ SOP และส่งออก/นำเข้าไฟล์ JSON ได้
   - 🍳 **Kitchen Staff (ฝ่ายครัว):** แสดงมุมมองการหมักไก่ การทอดไก่ (สะโพกไก่/ปีกไก่) พร้อมค่าอุณหภูมิ และเวลาทอด
   - 🛎️ **Front of House (หน้าร้าน):** แสดงมาตรฐานการเสิร์ฟ การคลุกซอส 4 สูตร การแพ็กสินค้า และการตักเครื่องเคียง

2. **ระบบการจัดการ SOP ที่ครอบคลุมเมนูในร้าน:**
   - 🍗 **ไก่ทอด 2 ส่วน:** สะโพกไก่ (Chicken Thigh) & ปีกไก่ (Chicken Wings)
   - 🥣 **ซอส Signature 4 รสชาติ:** ซอสเกาหลีเผ็ดหวาน, ซอสกระเทียมโชยุ, ซอสมัสตาร์ดน้ำผึ้ง, และซอสหม่าล่าสไปซี่
   - 🍚 **เมนูเครื่องเคียง & ซุป:** ข้าวญี่ปุ่น, เฟรนช์ฟรายส์, กิมจิ, ไชเท้าดอง, และซุปกิมจิหม้อร้อน
   - 🧹 **สุขอนามัยและความปลอดภัย:** การเปลี่ยนน้ำมันทอด การล้างมือ การคุมความเย็น และหลัก FIFO

3. **เครื่องมืออำนวยความสะดวกสำหรับพนักงาน (Kitchen Tools):**
   - ⏱️ **Cooking Timer Widget:** นาฬิกาจับเวลาถอยหลังสำหรับการทอดแต่ละรายการ พร้อมเสียงแจ้งเตือน
   - 🧮 **Batch Recipe Calculator:** ปุ่มคำนวณปริมาณวัตถุดิบอัตโนมัติ เมื่อต้องเตรียมวัตถุดิบปริมาณมาก (เช่น 2x, 5x, 10x)
   - 🔍 **Global Search Filter:** ค้นหาคู่มือ SOP ด้วยคำสำคัญใดๆ ทันที

4. **แก้ไขข้อมูลได้ง่าย (Easy CMS & Local Storage Persistence):**
   - แอดมินสามารถคลิกปุ่ม **"✏️ แก้ไข SOP นี้"** หรือ **"➕ เพิ่ม SOP ใหม่"** เพื่ออัปเดตข้อมูลได้ในหน้าเว็บทันที
   - บันทึกข้อมูลอัตโนมัติลงใน LocalStorage ของเบราว์เซอร์
   - รองรับการ Export / Import ข้อมูลเป็นไฟล์ `.json` เพื่อสำรองหรือย้ายเครื่อง
